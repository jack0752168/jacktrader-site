聯盟 vs Sub-Broker vs 介紹經紀：哪個返傭最高

在加密手續費返傭裡，有三個詞幾乎被當成同義詞混著用——聯盟（affiliate）、Sub-Broker、介紹經紀（IB）——而它們之間的差別，正悄悄決定你能拿回多少手續費。它們不是同義詞，而是同一座梯子上不同的層級，各有不同的佣金區間與義務。這篇講清楚每個詞真正的意思，以及怎麼一眼看出一個返傭方案站在哪一層。

三個詞，去掉行話的定義

聯盟（Affiliate）。自助式的推薦夥伴。你透過交易所的聯盟後台申請、通過審核後，賺取你推薦的交易者所付手續費的一個百分比。這個百分比隨你整棵推薦樹的總交易量提升。Google 上大多數「加密返傭」站都跑在這一層。

Sub-Broker。聯盟之上的那一層。由交易所在交易量與 KYB（瞭解你的企業）審核後個別導入。你拿到更大、可自訂的佣金區間，外加營運面的附加：逐筆對帳 API、交易所的專屬商務對接，以及更高的回饋上限。

介紹經紀（IB）。這個詞借自傳統金融——IB 把客戶介紹給清算經紀商、並從其活動中賺取分成。在加密裡，它幾乎完全對應 Sub-Broker／機構渠道：一個正式、合約化、負責介紹交易者並分得手續費的關係。不同交易所用不同的詞，但實質是同一層。

所以實務上的層級是：預設推薦 < 聯盟 < Sub-Broker／介紹經紀 < 做市商。返傭真正的大跳躍，發生在 Sub-Broker／IB 這條線。這一跳的完整定價機制，我們在 OKX Sub-Broker vs 聯盟拆解 裡講得更細。

為什麼 Sub-Broker／IB 這一層付得更多

關鍵在交易所往上游送的毛分成。聯盟的毛佣金被自己推薦樹的交易量限制住；Sub-Broker 則在導入時談下更大的毛分成。兩邊的營運方都會留一份利潤，去支應結算工程、客服、合規與自己的獲客成本——但 Sub-Broker 起跳的那塊餅更大，所以最後到你手上的那一片也更大。

具體來說：如果一個聯盟拿到 50% 毛分成、再把一半讓出去，那就是 25% 的實際返傭。一個站在更大毛分成區間的 Sub-Broker，照同樣比例讓出去，就落在接近 40%。同樣的交易、不同的層級，現金回饋大約翻倍。這正是我們在 返傭最高的交易所比較 裡走過的同一套算術——在你知道它站在哪個基數之前，那個對外的百分比毫無意義。

法律上最關鍵的那條「單層」線

這三者每一個合法版本都共享一件事：它們都是單層的。夥伴從它直接介紹的交易者的手續費中賺取分成；交易者拿到自己手續費的返傭。沒有人靠招募一串在自己底下的下層推薦人而獲利。

如果一個「返傭」方案付錢叫你建下線——招募會再去招募別人的人——那它就不再是聯盟、Sub-Broker 或 IB，而是多層結構，它牴觸交易所的推薦政策，在許多司法管轄區還帶有真實的法律風險。本文描述的這些誠實渠道從不這樣運作，任何下線／多層的話術都該被你當成警訊。

怎麼看出一個返傭方案站在哪一層

  1. 直接問層級。「你是聯盟、Sub-Broker，還是介紹經紀？」一個明確的答案告訴你上限在哪。含糊其詞，通常代表是聯盟。
  2. 要求逐筆對帳。Sub-Broker／IB 渠道能從帳本秀出每一筆交易的確切手續費。如果他們只能給你每週彙總，那就是站在較薄的那一層。
  3. 確認結算幣別與週期。USDT、每週，是正規渠道的標準。代幣積分、「活動獎勵」並不等於手續費返傭。
  4. 確認是單層。如果招募其他推薦人是話術的一部分，走人。
  5. 看交易所折扣歸誰。你的 BNB／OKB 與 VIP 等級折扣屬於你、疊在返傭之上——不屬於渠道。

常見問題

加密裡的介紹經紀（IB）是什麼？+
介紹經紀（IB）是把交易者帶到交易所的合作夥伴，通常有正式甚至合約關係，並從這些交易者產生的手續費中分得一份。這個詞源自傳統金融。在加密裡，它和交易所所稱的 Sub-Broker 或機構渠道高度重疊：一個經導入、有自訂佣金區間與回報義務的實體，位階高於自助申請的聯盟計畫。
聯盟和 Sub-Broker 有什麼差別？+
聯盟是透過自助計畫申請加入，賺取被推薦交易者手續費的一個百分比，比例隨交易量提升，通常把合約手續費的 20 到 25% 回饋給交易者。Sub-Broker 是再上一層：經交易量與 KYB 審核後個別導入，擁有更大的毛佣金分成、逐筆對帳 API 以及專屬交易所對接，因此把回饋上限拉到合約手續費的最高 40%。
哪一種渠道把最高的返傭回饋給交易者？+
Sub-Broker 或介紹經紀渠道，因為它起跳的毛佣金分成就比標準聯盟大。即使營運方留下一部分當作結算與支援的利潤，Sub-Broker 仍能把你合約手續費的最高 40% 回饋回來，而一般聯盟站大約是 20 到 25%。營運方對外打的那個百分比，遠不如它實際站在哪一層重要。
介紹經紀等於多層或下線制度嗎？+
不是。合法的加密介紹經紀或 Sub-Broker 關係是單層的：夥伴從它直接介紹的交易者的手續費中賺取分成，而交易者拿到自己手續費的返傭。它不是下線、不是多層結構，你也不會因為招募其他推薦人而獲利。任何付錢叫你去招募一串下層推薦人的制度，是完全不同、而且風險更高的東西。
聯盟、Sub-Broker、IB 的返傭會改變我的交易成交方式嗎？+
不會。這三種渠道的返傭都是針對交易所已經向你收取的手續費所做的現金回饋，另外發放——通常每週以 USDT 結算。你的下單路由、成交、槓桿與帳戶行為，有沒有掛返傭渠道都一模一樣。三者唯一的差別，是有多少手續費回到你手上、以及對帳乾不乾淨。
