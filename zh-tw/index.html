40% 返傭是怎麼來的？+
你在交易所交易會產生手續費，作為獨立的推薦返傭夥伴，我們會拿到這部分手續費的返傭，再把其中最高 40% 實時結算返還給你。比例隨平台政策、帳戶狀態和交易量浮動，以實際審核為準。
返傭怎麼發放、多久到帳？+
官方後台實時結算手續費，按你交易的原幣種返還，並提供明細，可結合交易所後台手續費記錄核對。

可以先評估。需要確認帳戶是否已有推薦關係、是否符合平台規則，再判斷能否綁定、遷移或用新帳戶重新規劃。聯絡 Telegram @Jack168668 評估即可。
有沒有最低交易量要求？+
沒有最低門檻。無論每月交易 $100 還是 $100 萬，都按相同規則返還手續費返傭。
安全嗎？會動我的資產嗎？+
返傭透過交易所官方推薦機制完成，不需要轉移資產，不索要私鑰、助記詞或 API 權限，不改變你的正常交易路徑。所有手續費都能在交易所後台自行核對。
現貨和合約都能返嗎？+
都可以。現貨與合約手續費返傭均覆蓋，長期高頻和中大戶使用者改善更明顯。
